# UniAI

## Description
A web-based system for scheduling and managing academic advisory sessions between students and teachers.  
The administrator registers courses and manages users, while students and teachers coordinate advisories through an integrated calendar and notifications.  
Each user has access to an AI-powered chat assistant that supports communication and helps optimize advisory scheduling.

## Features
- User roles: Student, Teacher, Administrative
- Advisory sessions: Request, schedule, and manage meetings
- AI chat assistant: Personalized support for each user to improve advisory planning
- Calendar integration: Organize and visualize advisory sessions
- Notifications: Automatic reminders and updates for events and messages
- Communication tools: Direct chat between students and teachers
